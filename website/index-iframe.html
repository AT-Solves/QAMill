Deploy QAMill

🖥️ For Developers (Individual)

1

Install VS Code Extension

Search "QAMill" in VS Code Extensions marketplace

code --install-extension qamill-mutation-testing-1.2.2.vsix
2

Choose LLM Provider

Select from: Claude, GPT-4o, Ollama (free/offline), Grok, Gemini

VS Code Settings → amil.llmProvider
3

Generate Tests

Right-click any Python/JS/TS file → QAMill → Unit Tests

Watch tests generate in 30-60 seconds
